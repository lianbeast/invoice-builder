# Installation

Invoice Builder is available as a desktop application (Windows, Linux, macOS) and as a self-hosted web application via Docker.

## Try the live demo

[Open the public demo](https://invoice-builder-sha-a014125.onrender.com) to try Invoice Builder without installing anything.

:::warning[Sample data only]
This Docker demo runs on Render's free plan and may take a moment to wake up. Databases may be accessible to other visitors and can disappear without notice. Do not upload real invoices, personal information, or database credentials.

The demo runs on a hosted server, not your device. Desktop and self-hosted installations store data on your own device or configured server and are separate from this demo.
:::
